# MaxChat Theme Packs

This folder contains 59 paired MaxChat app/chat theme packs, 59 preview PNG files, and 30 bundled wallpaper images.

Each `.json` file is a `maxchat-theme-pack` with both application chrome colors and chat rendering colors. Packs may also include a `wallpaper` value that points to a file in `wallpapers/`.

## Theme Builder

Open `theme-builder.html` in a browser to load presets, adjust app colors, adjust chat colors, choose wallpapers, set six font areas, preview the result, and save a new theme-pack JSON file.

The builder is standalone and does not require a web server. If a wallpaper filename is selected, the preview loads it from `wallpapers/`. Custom paths and URLs can be typed with the Custom wallpaper option.

## Font Presets

The builder includes multiple font presets: no bundled fonts, JetBrains Mono bold, JetBrains Mono regular, compact, comfortable, terminal/BBS, comic UI, large accessible, and custom per-area settings.

MaxChat currently ships JetBrains Mono, which covers the box drawing and block glyphs used by IRC, BBS, and ANSI-style layouts without adding another font dependency.

## How To Install

Copy the `.json` theme pack into the MaxChat themes directory used by the app build. Keep referenced wallpaper files in the app wallpaper directory or update the theme JSON to point at a different path.

## Naming Notes

The Fantasy Raid and Tank Garage themes are original game-inspired palettes. They avoid third-party logos and copyrighted artwork while still covering the MMO and armored-combat moods requested for testing.
